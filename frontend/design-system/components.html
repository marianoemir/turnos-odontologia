Cómo se consume

La fundación es portable: no depende de un framework de CSS ni de una cuenta externa.

tokens.css — importar una vez en el punto de entrada del frontend (o copiar sus variables a un archivo de tema). Es la fuente de verdad de color, tipografía, espaciado, radios, sombras, foco y motion.

brand.js — completa todo [data-brand-name]. Cambiar el nombre del producto es editar una constante.

assets/logo.svg — ruta estable del logo. Hoy es un placeholder con la leyenda PROV.

components.html — este archivo: referencia visual y de estados, no se compila ni se publica.
