## Changes

- `apiRequest` now removes caller-supplied `Authorization`, `X-Actor-Rol`,
  `X-Actor-Usuario`, and `X-Sucursal-Id` through the case-insensitive
  `Headers` API before it adds request defaults. Protected requests add only
  the in-memory session Bearer; public requests add no identity.
- Added protected and public injected-header tests, including mixed casing and
  preservation of a non-identity request header.
- The Vite proxy target can be overridden with `VITE_API_PROXY_TARGET`, while
  retaining `http://localhost:8000` as the development default.
- The proxy integration fixture starts its fake backend on port `0`, points
  Vite at that resolved address, restores its temporary environment setting,
  and conditionally closes only created/listening servers. Cleanup uses
  `Promise.allSettled` so it does not replace a setup failure.
- The integration fixture occupies port 8000 when available; when an
  independent listener already owns it, it leaves that listener untouched and
  still runs the two proxy rewrite assertions.
